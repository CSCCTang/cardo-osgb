# 体检判据（05 · H-01…H-06）

> 适用范围：`Skills/05-模型体检/scripts/inspect_model.py` 产出的 `cardo-lowair-model.json`、`体检.json`、`模型体检.md`。
> H-01…H-06 由本技能 `scripts/tiles_inspect.py` 的 `health_of()` 计算，写入 `health.checks`；
> `health.verdict` 规则：**任一 fail → fail；有 warn → warn；否则 pass**。

## 总则

- 判据对象是**转换产物**（3D Tiles 容器），不是 OSGB 原始字节；本链不解析 OSGB。
- 05 **不改**产物（b3dm/tileset 由 03 生成、04 改 transform），只复扫；**先删旧** `cardo-lowair-model.json`、
  `体检.json`、`模型体检.md`、`契约自检.json` 再生成。
- 05 的退出码：0 = pass/warn 且契约自检与一致性全过；2 = 缺输入/schema 不符；**3 = 任一 fail 或契约/一致性不过**。
- 拿不到的数值一律 `null` + `gaps[]`，不填 0、不估算。
- `check_contract.py` 是**结构 + 文件存在**双闸：`artifacts[].path` 必须相对 model 所在目录存在（且不含 `..`），
  且 `tiles.b3dmCount` 必须等于 artifacts 内 `.b3dm` 条数；任一不成立 → exit 2（错误信息列出前 5 条）。
  它不重算几何，几何真值由 H-01…H-06 与 03 的产物自扫兜住。

## H-01 文件数一致

- **判据**：`tiles.b3dmCount` == 输入 `Data/<Tile>/` 下的 osgb 数量（`view.blocks` 求和）。
- **口径**：只统计块目录内的 osgb；顶层 `Data/*.osgb` 不计入"应转数"，单独记 `TILE_NOT_CONVERTED` 信息码。
- **判定**：数量一致且顶层文件合计 ≤ 4096 B → pass；一致但顶层有"大文件" → warn；不一致 → fail。
- **失败动作**：核对输入是否缺块目录、瓦片是否被工具跳过；**禁止**手工补 b3dm。

## H-02 瓦片引用完整

- **判据**：根 `tileset.json` 递归（含外部块 tileset）引用的每个 `content.uri` 都存在；
  每个 b3dm 头部 `byteLength` 等于文件实际字节、GLB 长度自洽、JSON chunk 可解析。
- **口径**：只读标准容器（b3dm 头 + GLB chunk）；不读 OSGB。
- **判定**：引用缺失 0 且解析失败 0 → pass；否则 fail。
- **失败动作**：坏瓦片属工具 fail-open，重跑 03 / 换输入；产物不得进入 06 之后的交付链。

## H-03 LOD 计数

- **判据**：按文件名 `_L<level>_` 统计，输入 osgb 与产物 b3dm **逐级相等**。
- **口径**：LOD 层级来自文件名，不是 tileset 嵌套深度；无 `_L` 的块根瓦片由 `tiles.rootTiles` 单列。
- **判定**：完全相等 → pass；产物某层少于输入 → fail；产物层多于输入/差异不可解释 → warn。

## H-04 纹理缺失

- **判据**：每个 b3dm 内 glTF 的 `images[]` 都能落到有效 `bufferView`（`byteLength > 0`）；
  `textures.missingImages == 0`。
- **口径**：`images` 计张数，`materials` 计材质数，`bytes` = Σ`image.bufferView.byteLength`；
  外链 `image.uri` 不计缺失也不计字节。
- **判定**：缺 0 → pass；有缺失 → fail；无纹理（`images == 0`）→ warn（可能输入本身无贴图）。

## H-05 配准修正量已应用

- **判据**：`root.transform` 是 16 元素；`|修正后平移 − 修正前平移| == |appliedM|`（容差 1e-6 m），
  且 `appliedM = SRSOrigin.z`（`C-02` 再按 1 cm 对 |
  SRSOrigin.z|）。
- **口径**：
  - `appliedM` / `georeference.verticalOffsetM` = **已施加的修正量**，本模型 `+527.427 m`（正 = 沿 up 补高）；
  - `offsetM`（04 的 `配准修正.json`）= **检测偏差**，`−527.427 m`（负 = 工具产物原偏低）；
  - `up` 由 ECEF 反算的 geodetic 经纬度给出；修正沿 up 叠加，因此 x/y 也会变（本模型 −110.327 / +440.743 m）。
- **容差**：`georeference.translationToleranceM = 0.01`（1 cm）：SRSOrigin 六位小数 + ECEF 迭代可致 ≤1 mm 差，不判为误差。
- **判定**：位移量成立 → pass；transform 缺失或位移不等于 `SRSOrigin.z` → fail。
- **失败动作**：重跑 04；**禁止**手工改产物 transform（会破坏水平配准）。

## H-06 工具版本/完整性

- **判据**：02 探测通过（exe sha256、178 文件清单指纹、`-V` 字面量）；
  可选校验器 `3d-tiles-tools` 0.5.4 的整树 `convert` 成功。
- **口径**：完整性判定**只认** `Skills/02-工具探测/scripts/verify_tools.py`；本链不自带第二份白名单。
- **判定**：白名单命中 + 全量校验 pass → pass；白名单命中但校验器 skipped → warn；任一不符 → fail。
- **失败动作**：工具层不符先修 02（`probe_tools.py` / `fetch_tools.py`）；产物层不符重跑 03。

## 05 附加一致性（C-01…C-05，同样硬闸）

| 编号 | 判据 | 不过的处置 |
|---|---|---|
| C-01 | b3dm 数 = 输入块内 osgb 数 | 重跑 03 |
| C-02 | `|appliedM| == |SRSOrigin.z|`（≤1 cm） | 重跑 04 |
| C-03 | 04 的 `recomputeOk = true` | 重跑 04，检查 `.work/04-applied.json` |
| C-04 | 产物规模与 03 日志一致（b3dm 数硬对；字节允许 ≤4096 B 格式差，因 04 重写根 tileset） | 重跑 03/04 |
| C-05 | 转换所用 exe 与 02 登记同源 | 修 02，禁用未登记版本 |

## 质量与兼容（`quality` 块，v1.1 新增）

六项判据之外，`inspect_model.py` 还输出 `quality`（不替代 H 项，但 `status=fail` 会阻断 05）：

| 项 | 口径 | 阈值 → 判定 |
|---|---|---|
| 退化三角形 | 重复索引（i0==i1 等）占三角面比（下界，零面积未算） | >30% fail；>10% warn |
| 纹理缺失 | `missingImages` | >0 fail |
| 法线覆盖 | 有 `NORMAL` 的 primitive 占比 | <60% warn（指标只能退回全顶点） |
| UV 覆盖 | 有 `TEXCOORD_0` 的 primitive 占比 | <60% warn（无法做纹理采样） |
| 纹理分辨率 | JPEG SOF / PNG IHDR 头解析（不解码像素） | 全部解析失败 → warn |
| glTF 扩展 | `extensionsUsed` | 含 `KHR_techniques_webgl` → 仅提示查看器兼容 |
| 瓦片重叠 | 两两 x/y IoU，IoU≥0.5 计重叠对 | 仅提示（LOD 空间重叠属正常） |
| LOD 分组 | 按 `_L<level>_` 统计瓦片/三角面/顶点/字节/面占比 | 仅提示；面占比可量化 LOD 混合影响 |
| 纹理颜色诊断 | Pillow 解码内嵌纹理缩略图 → 逐图颜色占比；再按朝上三角面重心 UV 采样到 1.0 m 网格 | **仅诊断**（`usage=diagnostic-only`、`notValidated=true`），不进 7 条指标、不映射平面用地面积 |

本模型：176 图元 / 法线 1.0 / UV 1.0 / 退化 0 / 纹理 128×128–1024×1024（4 种）/ JPEG 176 /
扩展 `KHR_techniques_webgl` / 重叠 40 对 → `quality = pass`。

## gaps 码表（唯一口径；脚本只产表内码，`check_contract` 按此校验）

`gaps[]` 元素固定五段式 `{code, what, why, need, owner}`；`code` **必须**是下表 9 个之一。

### 错误码（6 个）

| code | 含义 | 触发点 | 退出码 |
|---|---|---|---|
| `TOOL_MISSING` | 工具/校验器缺失（工具目录、`3dtile.exe` 任一不在位） | `probe_tools` | 2 |
| `TOOL_VERSION_MISMATCH` | exe sha256 / 178 文件清单指纹 / `-V` 字面量 / 校验器版本与白名单不符 | `probe_tools` | 3 |
| `TOOL_FAILED` | 工具非零退出 / 超时 / 启动失败 | `convert`（03） | 3 |
| `ARTIFACT_INCOMPLETE` | 产物不完整：引用缺失、b3dm 截断、纹理缺失、H 项 fail | `convert`（03）、`inspect_model`（05） | 3 |
| `LICENSE_UNVERIFIED` | 许可未核验（缺许可原文）；**不阻断**主流程 | `probe_tools` | 不改变退出码 |
| `SRS_UNSUPPORTED` | 输入坐标系不可用：缺 `<SRS>` / `<SRSOrigin>` 不可解析 / 非 `EPSG:4544` | `unpack_model`（01） | 5 |

### 信息码（3 个，不改判）

| code | 含义 | 触发点 |
|---|---|---|
| `SRS_COMPOSITE_NORMALIZED` | 复合码 `EPSG:4544+<垂直码>` 已归一为单码 `EPSG:4544` | `unpack_model`（01）、`inspect_model`（05） |
| `TILE_NOT_CONVERTED` | 顶层 `Data/*.osgb` 未单独出 b3dm（索引/占位，工具只遍历块目录） | `inspect_model`（05） |
| `ASCII_PATH_WARN` | 规范化视图/输出路径含非 ASCII 字符（实测可跑通，仅告警） | `unpack_model`（01） |

口径备注：

- **可选校验器缺失不产 gap**：`3d-tiles-tools` 未安装时只把 `validation.status` 置 `skipped`，
  并在 H-06 记 warn（不阻断）。
- 退出码归属：`unpack_model` 0/2/3/4/5；`probe_tools` 0/2/3；`convert` 0/2/3；`fix_registration` 0/2/3/4；
  `inspect_model` 0/2/3；`check_contract` 只 0/2。

## 扩展键（`cardo/lowair-model/v1`）

- `crs.originalSrs`：metadata.xml 的原始 SRS 串（复合码时保留，便于追溯）。
- `health`：H-01…H-06 结构化结果 + `verdict`。
- `validation`：可选 3d-tiles-tools 全量校验（status / tool / durationMs / detail）。
- `georeference`：`verticalOffsetM`、`translationBefore/After/Delta`、`up`、`translationToleranceM`（固定 0.01）、`state`。
- `conversion`：转换退出码、耗时、产物字节（与 03 日志对账）。

## 口径备注

- `tiles.maxContentDepth`：从根 tileset 起算，子节点 +1、经 `content.uri` 进入外部 tileset 再 +1；本模型 = **8**。
- `tiles.count` = tileset 引用的 b3dm 内容数；与磁盘 b3dm 数不一致即 fail。
- `generatedAt` 是唯一每次都变的顶层字段；幂等比对**按结构与统计量**，不按 b3dm 字节/sha256（工具产物字节非确定）。

## 不判什么（避免越界）

- 不判模型**精度**（无片区级真值，不声称误差/测绘级）；
- 不判**视觉可加载**（本机无三维查看环境，只到"结构可解析"）；
- 不判 `KHR_techniques_webgl` 的查看器兼容性。
