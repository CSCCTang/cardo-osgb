# 验证规则（08）

## 1. 独立性底线

- 不复用 `run_indicators.py` / `tiles_inspect.py` 的任何函数或中间产物；
- 复算只吃两样东西：`cardo-lowair-model.json`（bbox + artifacts 清单）和 b3dm 文件本身；
- 允许"同方法、不同实现"；不允许"读 06 的 sensitivity 再拼一个值"。

## 2. 容差（写死在脚本常量，改动须同步本文件）

| 项 | 容差 | 理由 |
|---|---|---|
| 建筑密度 | ±0.002 | 06 保留 6 位；两套实现网格键取值一致（同 bbox、同 ceil） |
| 栋数 | 0 | 连通分量对同一 mask 必然一致，不设容差 |
| 高度 P50 / P90 | ±0.011 m | 06 保留 2 位小数 |
| 容积率 | ±0.0011 | 06 保留 4 位小数 |
| 范围面积 | ±0.02 m² | 06 保留 2 位小数 |
| 地面 z | ±0.002 m | 06 保留 3 位小数 |
| 基线的垂直修正量 | ±0.01 m | 与 04 的 1 cm 容差一致 |

超容差 = 失败（exit 3），不能"看着差不多就放过"。

## 3. 基线口径

- 文件：`记忆与规则/验证基线-CardoOSGB.json`（`cardo/lowair-baseline/v1`）。
- 存在 → 逐项对账（指标、产物规模、范围、垂直修正量）。
- **整份删除** → `B-00 = skip`，只做结构自洽，跳过项不算失败。
- 基线只属于**一个模型**；`scaffold` 不复制它，新工作区首跑后重新生成。
- 写基线时机：全链通过 + 08 独立复算 0 失败之后；此后每次回归都对它。

## 4. 边界口径

| 目录 | 允许 | 备注 |
|---|---|---|
| `输入文件/` | `.osgb .zip .xml .json .txt .xlsx .docx` | 本任务允许原生非 Office 输入 |
| `成果文件/` | `.xlsx .docx .pdf` | 恰好三件：体检报告 docx、指标 xlsx、指标说明 docx |
| `Skills/` | `.py .md .yaml` | `NN-*/tools/**` 例外：第三方工具可自带任意数据/二进制，但禁放 `.osgb/.b3dm/.glb/.gltf/.3dtiles/.3tz/.las/.laz/.ply/.obj` |
| `过程文件/` | 任意 | 但 b3dm/tileset 不得出现在成果目录 |
| `CardoOSGB/runtime/` | 任意（豁免） | 随包分发的**只读**便携 Python 运行时，其 `site-packages` 自带的 `.pyc` 属构建期产物，不是运行残留 |

附加：`Skills/` 下的 `.py/.md/.yaml` 不得含盘符绝对路径；
**工作区（不含技能包自带的 `CardoOSGB/runtime/`）不得有 `__pycache__` 或 `.pyc`**。

> 口径说明（2026-10-30 修订）：E-04 原按「全工作区」扫描，会把随包分发的便携运行时
> 里 pip 安装时自带的上千个 `.pyc` 判成违规——而技能包在运行期是只读的，那些字节码
> 不可能是本次运行产生的。故按**绝对路径**豁免技能包的 `runtime/` 目录；
> 不按目录名豁免，以免误伤用户在工作区自建的同名业务目录。
> 该 runtime 另配 `sitecustomize.pyc`（见 `runtime/README.txt`），自身不再写字节码，
> 所以豁免不会掩盖真实的运行残留。

## 5. 失败即停

任一项失败 → exit 3，并在 stdout 打出前 8 条失败（编号 + 名称 + 明细）。
处置顺序：先看 `验证报告.json.checks[].status=fail`，再决定重跑哪一步（通常是 06 或 07）。
