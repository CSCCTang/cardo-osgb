# 08 · 验证与边界

> 最后一关：**独立实现**复算指标（不 import 引擎脚本）、与 06 对账、与基线对账、扫描扩展名边界。
> 目的不是"再跑一遍"，而是"换一套代码算，结果还对不对"。

## 何时用

- 07 之后（`run` 最后一步）；
- 首跑通过后：自动生成 `记忆与规则/验证基线-CardoOSGB.json`（首跑自举，无需手工抄）；
- 基线被删后：只做结构自洽，基线项跳过（**跳过不算失败**）。

## 执行命令（工作区根）

```bash
python Skills/08-验证与成稿/scripts/independent_verify.py
python Skills/08-验证与成稿/scripts/independent_verify.py --workspace . --baseline-mode write   # 强制重写基线
python Skills/08-验证与成稿/scripts/independent_verify.py --workspace . --baseline-mode check   # 只对账不写
python Skills/08-验证与成稿/scripts/independent_verify.py --workspace . --baseline-mode none    # 跳过基线
```

`--baseline-mode`：

| 值 | 行为 |
|---|---|
| `auto`（默认）| 基线不存在 → **首跑自举写入**；已存在 → 对账 |
| `write` | 强制重写基线（换模型后用） |
| `check` | 只对账，基线不存在就跳过 |
| `none` | 完全跳过基线 |

基线内容与对账口径一一对应（`metrics` / `tiles` / `scope` / `registration`），
换模型时用 `--baseline-mode write` 重写，否则会拿旧基线对账而误报。

## 独立性

- 不 import `run_indicators.py` / `tiles_inspect.py`；
- 自己用 `struct` 逐顶点解析 `b3dm → GLB → POSITION + NORMAL`（**流式**，不缓存全量顶点）；
- 自己实现 1.0 m 网格、顶面筛选（`NORMAL.z ≥ 0.5`）、15 m 邻域 P10 地面、4 邻域闭运算与连通分量、最近秩分位；
- 只按 `规则/指标口径.md` 的**方法描述**复算，不读 06 的中间量反推。

## 对账项

| 组 | 检查 |
|---|---|
| V-01…V-05 | 建筑密度 / 栋数 / P50 / P90 / 容积率 与 06 点值一致（容差 0.002 / 0 / 0.011 m / 0.011 m / 0.0011） |
| V-01r…V-05r | 每个点值落在 06 声明的区间内 |
| V-06 / V-07 | 全局 P5 地面覆盖率、层高 2.8/3.3 的容积率都落在声明区间内（区间佐证） |
| V-08 / V-09 / V-10 | 范围面积、格数、地面 z、b3dm/顶点数与 06 一致；无解析失败 |
| V-11 | 绿化率 / 道路占比为 null（不编数） |
| V-12 / V-13 | 表面口径（`top`/`all`、法线覆盖、顶面格）与栋数闭运算（原始/闭运算分量数）可复算 |
| B-* | 基线对账（基线存在时）：5 个指标 + 产物规模 + 范围 + 垂直修正量 |
| E-01…E-05 | 输入/成果/Skills 扩展名白名单、无盘符路径、无 `__pycache__`、成果恰好四件 |

## 输出

| 文件 | 内容 |
|---|---|
| `过程文件/08-验证与成稿/独立验证结果.json` | 复算原值 + 全部 checks + pass/fail/skip 汇总（写基线就抄这里） |
| `过程文件/08-验证与成稿/验证报告.json` | 同上 + 输入清单 + 基线状态 + 边界扫描明细 + `ok` |

## 退出码

| 码 | 含义 |
|---|---|
| 0 | 无失败项（基线缺失导致的 skip 不算失败） |
| 2 | 缺 model / 现状指标 |
| 3 | 任一 V/B/E 项失败 |

## 调优点

- 容差写死在脚本常量里（覆盖 ±0.002、高度 ±0.011 m、容积率 ±0.0011），改动要同步 `规则/验证规则.md`；
- `Skills/**/tools/**` 允许第三方工具自带任意数据/二进制，但**禁止**放 `.osgb/.b3dm/.glb` 等模型或产物；
- 边界扫描只查 `输入文件 / 成果文件 / Skills` 三处，`过程文件` 不限扩展名（但 07 仍只往成果写 Office）。
