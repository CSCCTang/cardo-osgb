# 10 · 矢量入库 · 拓扑规则

> 原则：**只做确定性清理，不为凑数放宽阈值**。判不了的要素宁可丢弃并写清原因，也不猜。

## 处理顺序（顺序本身是规则的一部分）

```
读要素 → R8 属性完备 → R0 几何类型 → R1 精度 → R3 去重顶点 → R2 闭合
      → R3 退化判定 → R4 自相交 → R5 方向 → R6 面积 → R7 重复 → 写入
```

先做属性与类型，再动几何：属性不全的要素连几何都不用修，直接丢，省得修完再丢。

## 规则明细

| id | 名称 | 判定 | 处理 |
|---|---|---|---|
| R0 | 几何类型 | `type != "Polygon"` 或无外环 | 丢弃 |
| R1 | 坐标精度 | 按 `--precision`（默认 3 位）`round` | 统一取整，去掉浮点尾噪声 |
| R2 | 环闭合 | `ring[0] != ring[-1]` | 补首点 |
| R3 | 顶点去重 / 退化 | 相邻点完全相同 | 删重复点；闭合去重后 **< 4 点** 判退化丢弃 |
| R4 | 自相交 | 非相邻边两两求交（含端点落在边界上） | 命中即丢弃（修补会引入猜测，不入库） |
| R5 | 外环方向 | 鞋带**有符号**面积 < 0（顺时针） | 反转为逆时针 |
| R6 | 面积 | 鞋带面积 < `--min-area-m2`（默认 10 m²） | 丢弃 |
| R6 | 对账 | 鞋带面积 vs `widthM × heightM` 偏差 > `--area-tolerance`（默认 1%） | 保留 + 告警 |
| R7 | 重复几何 | 顶点序列指纹相同，或质心距离 < 0.05 m 且面积差 < 1% | 只留先出现的 |
| R8 | 属性完备 | `id/areaM2/heightP50/floorsEst/confidence` 任一缺失 | 丢弃 |

## 为什么"对账"不比 `areaM2`

`areaM2` 是**占地格面积**（格数 × 1 m²），而多边形是 **OBB 最小外接矩形**。两者天然差
`1 / fillRatio` 倍（本模型最大一栋 fillRatio 0.47，差一倍多）。
所以 R6 对账对象是 `widthM × heightM`（OBB 的两个边长乘积），这才是同一个几何量。

`属性表.csv` 里同时给 `areaM2`（占地）和 `areaRecalcM2`（OBB 鞋带面积），换算关系写进 `字段字典.md`。

## 自相交判定的边界情况

- 相邻边共享端点 → **不算**自相交（跳过 `j == i+1` 与首尾相邻）；
- 端点正好落在另一条边上 → **算**自相交（`on_segment` 判定），因为 OGC Simple Feature 也不允许；
- 退化（三点共线）只要不出现「边互相穿越」就不判自相交，交给 R6 面积阈值兜底。

## 精度取整的影响

3 位小数 = 毫米级，远小于本方法的几何不确定度（米级），因此 R1 不会改变任何结论，
只是让坐标在 SQLite/GPKG/前端里可复现、可作唯一键。`--precision 0` 会把 OBB 角点并到米格，
可能造成退化（< 4 点），此时按 R3 丢弃并在 `拓扑清理.json` 记明。

## 闸门是**回读**之后跑的

`build_vectors.py` 先落盘五个产物，再 `read_back()` 读回来做自检：
判的是「文件里实际写了什么」，不是内存里的中间态。这挡住「内存对象正确但序列化坏了」的假通过。

## 红线

- 不重算高度、不重算面积去覆盖 09 的属性（只新增 `areaRecalcM2` 做对账）；
- 不改 09 的 GeoJSON 原件（只读）；
- 不引入 GDAL 依赖硬要求（GPKG 用说明替代）；
- 产物里不写盘符绝对路径（`rel_ref` 保证）。
