# 导出核对规则（07）

## 1. 数字同源

| 成果 | 数字来源 | 禁止 |
|---|---|---|
| `成品版/模型体检报告/…_成品版.docx`、`内部件/模型体检报告/…_溯源版.docx` | `cardo-lowair-model.json` + `体检.json` + `转换日志.json.view.lods` | 手写任何数值 |
| `成品版/现状指标/…_成品版.xlsx`、`内部件/现状指标/…_溯源版.xlsx` | `现状指标.json.metrics / sensitivity / scope / params / gaps / diagnostics` | 补算未在 JSON 里的数 |
| `成品版/指标说明/…_成品版.docx`、`内部件/指标说明/…_溯源版.docx` | 同 `现状指标.json` | 用"约""大概"替代 JSON 值 |
| `内部件/现状指标/现状指标依据对照表.xlsx` | 同 `现状指标.json` | 缺口径、区间不包主值的数 |

## 2. 回读判据

- xlsx：`value / rangeLow / rangeHigh` 与 JSON 差 ≤ 1e-9；`name / confidence / grade` 字符串相等；按表头取列（两份列数不同）。
- docx：把段落 + 表格文本拼起来，检查关键值子串存在（模型名、b3dm 数、三角面、垂直修正、SRS、sha256、每条指标的可读值）。
- 两份同源：成品版与溯源版的指标行数（成品版剔除 C 级）、顺序、可读值、区间、置信度逐条相等。
- 成品版词表：全文扫描无「待补/暂缺/未配置/skipped/见过程文件/原始 + 数字/quality./本模型不含」等字样。
- 任一不符 → `exit 3`，不进入 08。

## 3. 口径措辞

- 区间必须写「方法敏感性区间（网格 0.5/1/2 m × 地面口径 × 层高 2.8/3.3 m）」，**不得**写误差/精度；
- 建筑栋数必须带「候选值，非报建口径」；
- 容积率必须带「非报建口径（层高未标定、分母为 bbox）」；
- C 级内部诊断指标（纹理代理的绿化率、道路占比）**只进溯源版**，成品版不出现。

## 4. 文件纪律

- `成果文件/` 只允许 `.xlsx .docx .pdf`；成品版与内部件分目录存放；
- 每项成果一个子目录，子目录内只放成品版、溯源版、必要附表；
- 每次导出先删同名旧文件；
- 不导出 JSON/MD 副本到成果目录（08 会扫描越界）。

## 5. 结论优先与缺口口径（四包统一）

- 每节/每张表先给结论再给数据；无实测值时给「初步判定 + 推断依据 + 置信度」，不写空节；
- **成品版**正文不出现「资料缺失/未提供/待补/占位/内部备注」；缺口只进**溯源版**，
  成品版用「方法适用边界 + 引用方式」把结论讲圆；
- 允许联网检索公开指标与同类案例补充参照，须写「来源：…；检索日期：YYYY-MM-DD」；
- 估算/推算值须同行标注「估算」与反算依据，不得编造具体数字或文号。
