# 转换与产物闸门（03）

> 3dtile.exe 是黑盒：本步只保证「调用正确 + 产物结构完整」，几何/纹理统计全部来自 b3dm 内嵌 GLB。

## 1. 调用前

| 检查 | 判据 | 失败处置 |
|---|---|---|
| 02 通过 | `工具探测.json.ok = true` | exit 3，先修 02 |
| 同源 | 现算 exe sha256 == 02 登记的 `sha256` | exit 3（不换版本试） |
| 输入 | 01 `输入清单.json` 存在且 `scene.dir` 可读 | exit 2 |
| 定位 | `metadata.srsOrigin` 三个数 | exit 2（04 依赖它） |

## 2. 规范化输入视图

- 目录：`<out>/.work/in-osgb/`；
- 内容：`metadata.xml` + `Data/<块>/<瓦片>.osgb`（**只拷 osgb**，其余文件不参与转换）；
- 顶层 `<Tile>.osgb` 直接放 `Data/` 根（不当块目录）；
- 每次运行前整目录重建（旧视图删掉），避免残留瓦片混入。

## 3. 产物统计口径（只读容器）

| 量 | 来源 | 说明 |
|---|---|---|
| b3dm 数 | 磁盘枚举（跳过 `.work`、`prev`） | 必须 = 输入块内 osgb 数 |
| tileset 数 | 磁盘 `tileset.json` 计数 | 根 1 + 每块 1（本模型 3） |
| 内容条数 | 根 tileset 递归 `content.uri`（含外部块 tileset） | 与磁盘 b3dm 数一致 |
| 最大深度 | 递归时 content 层数 | 本模型 8 |
| 三角面/顶点 | b3dm → GLB → 各 primitive 的 POSITION accessor.count、indices.count/3 | 不做去重 |
| 纹理 | GLB `images` 个数；缺纹理 = 无 bufferView 且无 uri | 本模型 176/176、缺 0 |
| 包围盒 | 各 accessor 的 min/max 取并集 | 局部坐标（米），Z 向上 |

## 4. 产物闸门（全部满足才 exit 0）

1. 退出码 0 且根 `tileset.json` 存在；
2. `b3dmDisk == Σ blocks`；
3. `b3dmDisk == len(contents)`（引用链闭合，无"文件在但没被引用"）；
4. `missing == 0`、`failed == 0`；
5. `missingImages == 0`；
6. `triangles > 0`。

不满足时写 `gaps[TOOL_FAILED]` 并以 exit 3 结束；`转换日志.json` 仍落盘（便于排障），但 `ok=false`。

## 5. 磁盘放大

`bytesOnDisk` = 产物总字节（b3dm + tileset）。本模型 37,784,742 B / 输入 28,125,520 B ≈ **1.343×**，
与既往基线一致；若显著偏离，先查输入是否被裁剪或工具版本被换。
