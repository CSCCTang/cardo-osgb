# 09 · 三维要素反演 · 口径

> 一句话：**用「朝上顶点 + 局部 P10 地面」把模型变成 nDSM，再用分水岭切栋**。
> 下面每条都是踩过坑之后定下来的，改任何一条都要重跑 06 对账。

## 1. DSM：只收朝上顶点

| 项 | 取值 | 为什么 |
|---|---|---|
| 表面口径 | `NORMAL.z ≥ 0.5` | 墙面顶点会把相邻建筑在同一格里连成一片，连通域整街区合并、逐栋高度被拉低 |
| 无 NORMAL 时 | 全用，并记 `REC-GAP-009` | 宁可口径降级并声明，也不静默丢顶点 |
| 格距 | 默认 1.0 m | 与 06 默认一致，方便对账；`--cell-m` 可调 |
| 每格取值 | `max z` | DSM 是「最高表面」，不是平均 |

本模型实测：顶面顶点 398,606 / 689,435（57.8%），与 06 的 `diagnostics.surface` 完全一致。

## 2. 地面参考面：局部 P10，**排除空洞**

```
ground(x,y) = P10{ dsm(u,v) : (u,v) 在 ±15 m 方形窗口内 且 有观测 }
```

- **为什么不是形态学开运算**：窗口一旦大于建筑，整片屋顶会被当成「地面」压下去，nDSM 归零、
  建筑整体消失。实测：`max(ground, minimum_filter(dsm,5)-0.5)` 让 mask 掉到 2,141 格、H50 只有 5.75 m。
- **为什么不是「最低点 + 开运算」**：每格最低点会被地面杂物和遮挡拉低，地形又被误判成建筑。
- **为什么排除空洞格**：空洞占 29%，若把空洞当最低值参与分位，地面被系统性拉低 →
  mask 暴涨（实测 3,996 格 vs 06 的 3,209 格）。排除后 **mask 3,209 格**，与 06 逐格对上。
- 全空窗口（极端）退回全局 P10。

## 3. nDSM 与 mask

- `nDSM = max(DSM − ground, 0)`，只在有观测的格上算；
- `mask = nDSM > 3.0 m`（`--building-threshold-m`，默认与 06 一致）；
- 形态学：**3×3 闭运算补洞 → 3×3 开运算去毛刺**。闭运算是「扩张性」的，会补进少量低于阈值的格，
  这些格参与面积但不参与高度分位的极端值（不影响 P50/P90 量级）。

## 4. 实例化：分水岭，不是连通域

```
smooth = gaussian(nDSM, sigma=1)
seeds  = peak_local_max(smooth, min_distance=round(6 m / cell), threshold_abs=3.0, labels=mask)
labels = watershed(-smooth, seeds, mask=mask)
```

- 连通域口径下，裙房/连廊把整街区连成一块：本模型最大块 2,819 格（≈2,819 m²）；
- 分水岭按「屋顶高点的分水岭脊」切开，实测 13 个 70–938 m² 的区域、逐栋 H50 4–15 m，
  符合「低矮构筑物 + 多层建筑」的合理分布；
- 种子间距 6 m：小于 6 m 会把一栋楼切成两半，大于 10 m 又会把裙房合回去；
- 没有 scikit-image 或 `--split-m 0` → 退回 `ndimage.label`，产物 `params.splitMode=connected-component` 明写。

## 5. 逐栋属性

| 字段 | 口径 | 备注 |
|---|---|---|
| `areaM2` | 格数 × 格面积 | 占地投影面积，**不是**建筑面积 |
| `heightP50/P90/Max` | 本栋 nDSM 的最近秩分位 / 最大 | 最近秩，不用插值，同输入必同输出 |
| `floorsEst` | `round(P50 / 3.0)` | 层高 3.0 m；区间按 2.8–3.3 m 给 `floorsRange` |
| `centroidXY` | 格中心均值 + `crs.origin` | 没有 origin 时是局部坐标并在 gaps 里说明 |
| `footprint` | OBB：宽 / 高 / 方位角 / 贴合率 / 四角 | 贴合率 = 格面积 / OBB 面积 |
| `confidence` | A/B/C | 见下 |

**降级条件**（命中任一即 C）：

- 面积 < 20 m²；
- 贴合率 < 0.40（异形，OBB 外扩严重）；
- 压 bbox 边界（可能是被裁断的物体）；
- 高度 CV > 0.60（可能混入树冠/附着物）；
- 与本栋 4 邻接的**遮挡空洞** ≥ max(5 格, 本体 25%)。

**A 级**：面积 ≥ 60 m²、贴合率 ≥ 0.60、CV ≤ 0.30、不压边界、无遮挡空洞；其余为 B。

## 6. 敏感性：只报区间，不报精度

- 固定三档地面窗口 **12 / 15 / 18 m** 重跑，取栋数/面积/高度的 min–max；
- 本模型：栋数 12–13、占地 3,053–3,275 m²、H50 中位 2.9–9.75 m；
- **区间是方法敏感性，不是精度**。没有真值（`REC-GAP-004`），任何「精度 ±X m」的说法都不成立。

## 7. 与 06 的关系

| 项 | 06 | 09 | 是否该相等 |
|---|---|---|---|
| DSM | 同口径（顶面顶点 + 每格 max z） | 同 | 是（实测 dsm P50 都是 −56.11 m） |
| 地面 | ±15 m 邻域 P10（仅观测格） | 同 | 是（实测 mask 都是 3,209 格） |
| mask | nDSM > 3.0 | 同 | 是 |
| 栋数 | 连通域（4 邻域闭运算） | **分水岭** | **否，口径不同，不要直接比** |
| 高度 P50 | mask 全部格的分位 | 逐栋 P50 的栋间中位 | **否** |

对账只看：`scope.observedCells`、`mask.rawCells`、DSM/ground 的分位量级。
