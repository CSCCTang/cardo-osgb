## 2. 产物（缺一件即视为未完成）

目录：`过程文件/11-几何增强/<slug>/`，`slug = id.replace(".", "-")`（如 `roof-segment`）。

| 文件 | 必须 | 内容 |
|---|---|---|
| `<slug>.json` | 是 | schema `cardo/lowair-enhance/v1`（`common.emit` 生成） |
| `<slug>.md` | 是 | 人读报告：方法、参数、结果表、局限（禁止编数） |
| `_done/<slug>.json` | 是 | `common.emit` 自动写，供总控判定完成 |

| 其它 | 否 | 栅格 `.npz` / 矢量 `.geojson` / 中间件，按算法需要 |

JSON 顶层：`schema / algo / generatedAt / inputs / params / summary / items / gaps / quality`。
- `summary`：扁平数值（可含 `null`），键名英文小驼峰；算不出就 `null`，**不许估一个数**。
- `gaps[]`：`{code, what, why, need}`，code 用 `ENH-GAP-<三位>`。
- `quality.usable`：产物是否可用；`false` 时 `reasons[]` 写清哪条闸门不过。

## 5. 算法口径（本技能只做 4 个；另 4 个已移交独立技能，互不写同一文件）

- 本技能（`Skills/11-几何增强/`）：§5.1 `pc.ground-filter`、§5.2 `pc.classify`、§5.5 `tree.single`、§5.6 `mesh.repair`。

- `Skills/13-矢量增强/`：§5.7 `vector.polygonize`、§5.8 `vector.gpkg`（产物落 `过程文件/13-矢量增强/`）。
- **同一份契约、各自的目录**：12/13 的脚本、产物、`_done`、`_patches` 全部只写自己目录，不改本技能任何文件；
  注册表合并由 11 的收口任务统一做（只读它们的 `_patches`）。

### 5.1 `pc.ground-filter` → `pc_ground_filter.py`
纯 Python 实现**渐进形态学滤波（PMF，Zhang et al. 2003）**，不用 PDAL。
输入 `dsm` + `observed`；窗口从 3 格递增到 33 格（步长 2），高差阈值 `dh = 0.5 + 0.02·w²`（w 为窗口格数，参数写进 JSON）。
输出地面面 `groundPmf`（`.npz` 存 `ground_pmf`）、与 09 的 P10 地面逐格对比：
`meanAbsDiffM / p95AbsDiffM / agreeWithin1m`；对 09 的 13 栋不产生负 nDSM（统计 `negativeNdsmCells`，必须为 0 或说明原因）。
`usable` 条件：`observed` 格全部有值、`negativeNdsmCells == 0`（或已写 gap 解释）。

### 5.2 `pc.classify` → `pc_classify.py`
用 `ndsm` + 局部粗糙度（3×3 `dsm` 标准差）+ 坡度，把观测格分为 `ground/building/vegetation/other`：
`ndsm ≤ 0.5` → ground；`ndsm > 3.0` 且粗糙度 ≤ 0.5 → building；`ndsm > 1.5` 且粗糙度 > 0.8 → vegetation；其余 other。
输出每类格数与占比、与 09 建筑 mask 的重合率（`buildingRecallVs09`）。
必须写 gap：无影像/无点云分类，仅几何启发式，**不能当语义真值**。

### 5.3 `roof.segment` → `roof_segment.py`
trimesh 或自实现：遍历 b3dm 面，按 `nz ≥ 0.7` 取屋面面片，用「法向半球量化 + 平面偏移聚类」得到屋面子段；
统计每段面积、倾角、平面度（`rmsM`）、所属建筑（按 09 `逐栋属性.json` 的质心最近邻，没有就 `null`）。
`summary` 至少：`roofPlaneCount / roofAreaM2 / meanTiltDeg / flatPlaneShare`。

### 5.4 `facade.normal` → `facade_normal.py`
取 `|nz| < 0.4` 的顶点法向，按方位角 15° 分箱 + 高度层（每 3 m）统计立面面积；
输出 `facadeAreaM2`、主朝向（4 个方位占比）、与 09 建筑 mask 的接触边长 `footprintEdgeM`。
必须写 gap：立面面积含山墙/围墙，未区分。

### 5.5 `tree.single` → `tree_single.py`
`chm = ndsm` 且排除 09 建筑 mask；`peak_local_max(min_distance=2.0 m, threshold_abs=2.0 m)` + 分水岭；
过滤树冠半径 < 1.0 m 的种子。输出 `treeCount / crownAreaM2 / meanCrownDiameterM / maxHeightM`。
必须写 gap：单木分割在密林会合并，`treeCount` 是下界估计。

### 5.6 `mesh.repair` → `mesh_repair.py`
用 `trimesh`（已安装）对每个 b3dm 的 GLB 做**只读诊断 + 副本修复**：
统计边界边数 / 非流形边数 / 孔洞数，`trimesh.repair.fill_holes` 在**内存副本**上补洞，报告补洞前后三角面数；
**绝不回写模型包**，修复副本只落 `过程文件/11-几何增强/mesh-repair/repaired/`（可删）。
`usable` 条件：所有 b3dm 可被 trimesh 加载。

### 5.7 `vector.polygonize` → `vector_polygonize.py`
用 `skimage.measure.find_contours` 从 09 建筑 mask 提取等值线（0.5），
**世界坐标 `X = origin[0] + x0 + ix·cell`、`Y = origin[1] + y0 + iy·cell`（`common.load_origin` 取 origin，缺失时用局部坐标并写 gap）**；
自实现 Douglas-Peucker（容差 0.5 m）简化 + 环闭合 + 方向统一；
输出 `建筑轮廓面.geojson`（EPSG:4544），与 10 的 OBB 对比面积比 `areaRatioVsObb`（中位）。
必须写 gap：栅格边界是锯齿状，未做直角规则化。

### 5.8 `vector.gpkg` → `vector_gpkg.py`
**只用 stdlib `sqlite3`** 写最小合规 GeoPackage：`gpkg_spatial_ref_sys`（含 4326/‐1/4544）、
`gpkg_contents`、`gpkg_geometry_columns`（GEOMETRY，srs_id=4544）、要素表（geom BLOB = GPKG 头 `b'GP'` + version 0 + flags + srs_id + envelope + WKB polygon）。
数据源 = 10 的 `矢量成果.geojson`（13 要素）。
写完**回读自检**：表存在、要素数=13、每个 geom 前 2 字节为 `GP`、srs_id=4544。
`usable` 条件：回读自检全过。若实现不了合规 blob，写 `usable=false` + gap，**不许写坏文件冒充**。
