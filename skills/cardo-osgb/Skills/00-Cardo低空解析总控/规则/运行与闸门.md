# 运行与闸门（00）

> 总控只做三件事：按序调度、卡退出码、留可追责的记录。本文件是纪律口径，实现见 `scripts/pipeline.py`。

## 1. 调度

- 每步一个**独立子进程**：`python Skills/<NN-技能>/scripts/<脚本>`，`cwd` 固定工作区根；
- 步骤顺序固定 `01→08`；`--from/--to` 只能截取连续区间，不允许跳步；
- 01 恒带 `--force`（staging 原子替换，重跑即重建）；未给 `--input-zip` 时只认
  `输入文件/01-模型包/` 里**唯一**的 zip（0 个或多个都直接 exit 2，不猜）。

## 2. 闸门

| 判据 | 口径 |
|---|---|
| 步通过 | 子进程退出码 = 0 |
| 失败即停 | 不继续后续步骤（下游会读半成品，必须阻断） |
| 不静默 | 打印并落盘该步 stderr 末段（≤2000 字），脱敏为 `<workspace>` |
| 先删旧 | 各步脚本自己负责（03 删产物、05/06/07 删同名产物、01 staging 替换） |
| 不假通过 | 只认退出码，不认"文件在不在" |

## 3. 记录

- `过程文件/00-总控/运行日志.json`（`cardo/lowair-run/v1`）：workspace=`<workspace>`、起止时间、总耗时、
  逐步 `{code,name,cmd,exitCode,durationMs,stdoutTail,stderrTail}`、`passed/ok/exitCode`、Python 版本。
- `过程文件/00-总控/运行报告.md`：步骤表 + 体检/指标/验证摘要（数值全部摘自各步 JSON）+ 失败定位
  （哪步、退出码、stderr 原文、修法 `--from <步>`）。

## 4. 退出码

| 码 | 含义 |
|---|---|
| 0 | 所选步骤全部通过 |
| 1 | 某步失败（已定位到步骤与 stderr） |
| 2 | 参数/工作区不合法（缺 `Skills/`、`--from/--to` 非法、输入 zip 不是恰好一个、目标已存在） |

## 5. scaffold

- 复制：`Skills/`（含 `02-工具探测/tools/` 与 LICENSE）、`输入文件/01-模型包/`、`README.md`、
  `工作区参数.json`、`requirements.txt`；忽略 `__pycache__`、`*.pyc`、`.work`。
- **不复制**：`过程文件/`、`成果文件/`、`记忆与规则/验证基线-CardoOSGB.json`（基线属于具体模型）。
- 生成 `SCAFFOLD.md` 说明怎么跑、换模型放哪。
