## 5. 算法口径

### 5.1 `roof.segment` → `roof_segment.py`

1. **LOD 选层**：先读全部 b3dm 的三角面并记录层级（路径 `_L19_2` → 19，无层级记 -1）。
   逐层算「mask 内 `nz ≥ 0.7` 的屋面面积」，取 ≥ 0.85×建筑占地（`maskCells × cell²`）的**最细层**；
   无层达标则取屋面面积最大层。只用该层，避免各层重复计数。
2. **屋面候选**：`nz ≥ 0.7`（法向取三顶点 `NORMAL` 面积加权均值，缺失/退化用叉积），
   且面重心落在 09 建筑 mask 格内（`ndsm > buildingThresholdM & observed` + close/open 3×3，自实现）。
3. **子段**：法向按方位角 15° + 倾角 5° 量化分箱；箱内 `d = n·centroid` 排序，
   相邻 `d` 差 > 0.5 m 切开；面积 < 2.0 m² 的子段不计入平面清单（面积仍计入 `roofAreaM2`）。
4. **统计**：每段面积（3D 三角面面积和）、倾角、`rmsM`（面积加权偏移标准差）、质心、面数、
   建筑归属（09 OBB 包含优先，否则最近质心 ≤ 60 m，仍无 `null`）。
5. **summary 必含**：`roofPlaneCount / roofAreaM2 / meanTiltDeg / flatPlaneShare`；
   另给 `segmentedAreaM2 / roofTriangleCount / nzRoofTriangleCount / subMinSegmentCount /
   buildingMatchedPlaneCount / unassignedPlaneCount / maskCells / lodLevel / b3dmCount …`。
   `roofAreaM2` 是 mask 内屋面三角面实测总面积；`meanTiltDeg / flatPlaneShare`（≤5°）按面积加权。
6. **items**：面积最大的前 20 段（`id / areaM2 / tiltDeg / azimuthDeg / rmsM / normal / centroidLocal / faceCount / buildingId / buildingMatch`）。
7. **gaps 必写**：未做 RANSAC 随机采样；屋面附属物未剔除；建筑归属近似；
   mask 过滤（地形/树冠按朝上面也会混入）；LOD 单层未跨层去重。

### 5.2 `facade.normal` → `facade_normal.py`

1. 与 5.1 同一 LOD 选层口径（判「屋面」用 `nz ≥ 0.7`）。
2. **立面候选**：三角面法向（三顶点 `NORMAL` 均值，缺法向用叉积）满足 `|nz| < 0.4`，面积取 3D 三角面面积。
3. **方位**：`az = atan2(nx, ny) mod 360`，正北（+y）为 0°、顺时针 15° 分箱；
   四方位 = 北 315–45°、东 45–135°、南 135–225°、西 225–315°。
4. **高度层**：3 m 一层，高度 = `max(面重心 z − 09 地面, 0)`（最近格）；地面缺值记 unknown，不参与分层与均值。
5. **`footprintEdgeM`**：按 09 参数重算建筑 mask（`ndsm > buildingThresholdM & observed` + close/open 3×3，自实现），
   数 4 邻接界面（含栅格外边界）× 格宽。
6. **summary 必含**：`facadeAreaM2 / footprintEdgeM / northShare / eastShare / southShare / westShare`；
   另给 `dominantAzimuthDeg / dominantShare / facadeTriangleCount / meanFacadeHeightM / maxFacadeHeightM /
   heightUnknownAreaM2 / heightLayerCount / maskCells / maskCells09 / lodLevel / b3dmCount …`。
7. **items**：24 个方位角箱（`kind="azimuthBin"`）+ 各高度层（`kind="heightLayer"`），人读表放 `.md`。
8. **gaps 必写**：立面面积含山墙/围墙/灌木侧面，未区分建筑与附属；法向/绕向翻向风险；
   高度层依赖 09 地面；`footprintEdgeM` 是栅格锯齿边长；LOD 单层未跨层去重。
