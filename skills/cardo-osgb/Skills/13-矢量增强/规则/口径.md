# 13 · 矢量增强 · 口径（v1）

> 本文件是 `vector.polygonize` 与 `vector.gpkg` 的确定性口径。所有数值必须由脚本实测，
> 算不出就 `null` + gap；不许估数、不许用坏文件冒充成果。

## 1. 坐标系与栅格映射

- 09 栅格：`axis0 = +x`、`axis1 = +y`，`cell = 1.0 m`；`x0 / y0` 是格网局部原点。
- 世界坐标（EPSG:4544）：
  `X = origin[0] + x0 + ix·cell`，`Y = origin[1] + y0 + iy·cell`。
- `origin` 只从 `common.load_origin`（模型契约 `crs.origin`）取；缺失时用局部坐标（`ox=oy=0`）
  并写 gap，**不拿 09 的 originOffset 偷偷替代**。

## 2. 建筑 mask（复刻 09）

```
raw     = (ndsm > buildingThresholdM) & observed          # 默认阈值 3.0
closed  = binary_closing(raw, 3×3 方形, 1 次) & observed
cleaned = binary_opening(closed, 3×3 方形, 1 次)
```

- 形态学按 09 `run_reconstruct.py` 同款：`np.ones((3,3))`、`iterations=1`；
  闭运算后再 `& observed`，开运算不再套 `observed`（这是 09 的实际口径）。
- 本脚本用纯 Python 实现，实测得到 `raw=3209 / closed=3330 / cleaned=3247`，
  与 09 的 `diagnostics.mask` 一致；不一致时写 gap，不掩盖。

## 3. vector.polygonize

- 等值线：`level = 0.5`；0/1 场的等值线落在格边中点（marching squares）。
  引擎：有 scikit-image 用 `skimage.measure.find_contours`；没有则用内置 marching squares
  （`fully_connected='low'` 鞍点口径），并写 gap 说明引擎。
- 简化：自实现 Douglas-Peucker，容差 `0.5 m`；闭合环在最远点切成两条开放折线分别简化。
- 环闭合：首尾点必须相同；去相邻重复点；简化后不足 4 点判退化丢弃。
- 方向：外环逆时针（鞋带面积 > 0），洞顺时针（< 0）。
- 面积：鞋带公式；**净面积 = 外环 − 洞**；净面积 `< 10 m²` 丢弃。
- 归属：若某环包含 10 的 OBB 质心，则该面记这些 OBB；`areaRatioVsObb = 净面积 / 包含的
  OBB 面积之和`；没有包含任何 OBB 质心的面，`areaRatioVsObb = null`（不硬凑）。
- summary：`polygonCount / polygonAreaM2 / areaRatioVsObb（中位，非 null 的比值）/
  vertexCountBefore / vertexCountAfter`。

### 必须写的 gap

- `ENH-GAP-001` 栅格边界锯齿、未做直角/45° 规则化。
- `ENH-GAP-002` 连通域合并相邻建筑（09 未落盘逐栋 label）。
- `ENH-GAP-003` mask 有格未被 09 实例覆盖（可能形成无 OBB 的小面）。
- `ENH-GAP-004` 缺 EPSG:4544 原点（条件触发）。
- `ENH-GAP-005` 无 scikit-image、使用内置等值线（条件触发）。

## 4. vector.gpkg

数据源：10 的 `矢量成果.geojson`（13 个 Polygon，EPSG:4544）。

### 4.1 SQLite 头

- `PRAGMA application_id = 1196444487`（0x47504B47 = `GPKG`）
- `PRAGMA user_version = 10200`（GeoPackage 1.2.0）

### 4.2 元数据表

| 表 | 要求 |
|---|---|
| `gpkg_spatial_ref_sys` | 必含 `srs_id = 4326 / -1 / 0`，另加自定义 `4544`（organization=EPSG） |
| `gpkg_contents` | `table_name='buildings'`、`data_type='features'`、`srs_id=4544`、bbox |
| `gpkg_geometry_columns` | `geom` / `POLYGON` / `srs_id=4544` / `z=0` / `m=0` |

### 4.3 要素表与几何 blob

- `buildings(fid INTEGER PRIMARY KEY, geom BLOB NOT NULL, id TEXT, areaM2 REAL, heightP50 REAL,
  heightP90 REAL, heightMax REAL, floorsEst INTEGER, floorsRangeLow INTEGER,
  floorsRangeHigh INTEGER, centroidX REAL, centroidY REAL, widthM REAL, heightM REAL,
  angleDeg REAL, fillRatio REAL, confidence TEXT, gradeReasons TEXT, geometryType TEXT,
  areaRecalcM2 REAL)`。
- blob 头：`b'GP'` + `version=0` + `flags=1`（小端、无 envelope）+ `srs_id=int32 LE(4544)`。
- WKB：小端 byteorder=1、type=3（Polygon）、环数、每环点数 + double 对；
  外环逆时针、内环顺时针、首尾闭合。

### 4.4 回读自检（必须全过）

1. 三张元数据表 + `buildings` 存在；
2. `application_id / user_version` 正确；
3. 要素数 = 13（与 10 一致）；
4. 每个 `geom` 前 2 字节为 `b'GP'`、version/flag 合规、header `srs_id=4544`；
5. 反解 WKB 的面积与 10 的 GeoJSON 面积相对偏差 `< 1%`。

任一条不过：**删除该 gpkg、`usable=false`、写 `ENH-GAP-001`**，绝不留下坏文件。
