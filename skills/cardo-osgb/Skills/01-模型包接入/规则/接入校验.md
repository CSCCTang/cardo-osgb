# 接入校验规则（01）

> 本文件写 01 的判据与"为什么"，实现见 `scripts/unpack_model.py`。判据变更必须同步本文件并全链回归。

## 1. 路径安全（硬闸，violations 必须 0）

| 拒绝项 | 判据 | 为什么 |
|---|---|---|
| 绝对路径 | `os.path.isabs(name)` 或含盘符 | 解包不能写到工作区之外 |
| 上跳 | 分段含 `..` | 同上，防 zip slip |
| 符号链接/设备 | 条目 external_attr 标记 symlink，或名称为 CON/NUL/COM1… | 防读到宿主设备或被链接带出 |
| 超大条目 | 单条目 > `--max-bytes`（默认 512 MiB） | 防解压炸弹 |
| 大小写冲突 | 归一后同名（不区分大小写） | Windows 下会互相覆盖 |

命中任一项：记录到 `safety.rejected[]` 并 `exit 3`（不做"部分解包也交付"）。

## 2. ASCII 归一

- 非 ASCII 字符改写成稳定 ASCII 片段（保留块名可读性），原→新写入 `safety.renamed[]`；
- 目的：3dtile.exe 与部分查看器对非 ASCII 路径不稳定；归一后仍能从清单找回原名。

## 3. 布局

- 期望 `metadata.xml` + `Data/<块目录>/*.osgb`；
- 顶层直接放 `.osgb` 是允许的（根节点），但只有几十~几百字节时通常是索引占位；
- 无 `Data/` 且没有任何 `.osgb` → `exit 4`。

## 4. SRS 口径

- 允许值：水平 **单码 `EPSG:4544`**（CGCS2000 / 3° 高斯，本任务样例）。
- 复合码 `EPSG:4544+5737`：**归一为** `EPSG:4544`，垂直码单独记 `metadata.vertical = EPSG:5737`，
  并在下游记信息码 `SRS_COMPOSITE_NORMALIZED`（不是错误）。
- 其它水平码 → `SRS_UNSUPPORTED`（`exit 5`）：本链未验证过其它带号，不能"猜着跑"。

## 5. metadata 处理

- 去 BOM（`utf-8-sig` 读、UTF-8 无 BOM 写），记录 `hasBom`；
- 解析 `SRS`、`SRSOrigin`（三个数，米）、`ColorSource`；
- `SRSOrigin` 缺失 → 后续 03/04 无法定位，直接 `exit 2` 并说明缺字段。

## 6. 可复算

`输入清单.json` 必须能回答：多少文件、多少字节、多少 osgb、分几个块、LOD 层级有哪些、
每个文件 sha256 是多少。后续步骤只信这份清单，不再回头读 zip。
