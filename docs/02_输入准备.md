# 输入准备（cardo-osgb）

## 文件清单

| 文件 | 必需 | 形态与要求 |
|---|---|---|
| OSGB 模型包 | 是 | 一个 zip；解压后只有一层根目录，根下有 `metadata.xml`，瓦片在 `Data\` 下；坐标系 EPSG:4544 |
| 其他材料 | 否 | docx / xlsx / pdf / 图片，放 `输入文件\` 任意层级 |

## 最小样例

本包不附模型。最小可用输入 = 一个能打开的单瓦片 OSGB 包（含 `metadata.xml`）；
先跑通再换全量数据。

## 摆放

```
D:\proj\osgb-01\
  输入文件\01-模型包\某某片区.zip
```

- 一个工作区只放一个模型；多个 zip 会被判为料不对。
- zip 内保持目录结构，不要压平瓦片层级。

## 不要放什么

- 与本项目无关的模型包。
- 已解包的散目录当唯一输入（请打回一个 zip）。
- 转换后的半成品当输入（那是本包的产出）。
