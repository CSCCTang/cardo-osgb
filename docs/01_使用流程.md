# 使用流程（cardo-osgb）

## 从哪进

在 dsh 对话里说一句即可：

> 用 cardo-osgb 跑，工作区是 `D:\proj\osgb-01`

工作区请用一个**独立空文件夹**。

## 给什么

1. 在工作区里建 `输入文件\01-模型包\`。
2. 把 OSGB 模型包打成**一个 zip**（解压后单根目录，含 `metadata.xml`），放进该目录。
3. 其余材料（情况说明、范围图等）可放在 `输入文件\` 下任意位置，有就放，没有也能跑。

## 拿到什么

跑完后在 `成果文件\` 下：

- 3D Tiles 模型包
- 模型体检报告（docx）
- 现状指标（xlsx）
- 指标说明（docx）
- 模型浏览页（双击 `Start.bat` 打开）

工作区里的 `过程文件\` 是过程留痕，交付时不用带走。
