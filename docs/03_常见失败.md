# 常见失败（cardo-osgb）

只看「看到什么 → 怎么办」。

| 看到的提示 | 怎么办 |
|---|---|
| 找不到模型包 / 多个 zip | 在 `输入文件\01-模型包\` 只保留一个 zip，重跑 |
| 坐标系不符（非 EPSG:4544） | 先用 GIS 工具重投影，再重新导出并打包 |
| 缺 `metadata.xml` / 布局不对 | 确认 zip 解压后只有一层根目录且含 `metadata.xml` |
| 包内缺转换器（提示安装包不完整） | 重新安装本插件（github 或 tgz） |
| 包内缺浏览引擎（提示安装包不完整） | 重新安装本插件；报告与指标不受影响 |
| 模型体检有 fail 项 | 报告会写明缺口；补齐模型或按报告结论据实交付 |
| 运行中提示工作区被占用 | 确认没有另一个任务在跑同一工作区，稍后重试 |

排查顺序：先看工作区 `过程文件\` 里的最新记录，再按上面的提示对照处理。
